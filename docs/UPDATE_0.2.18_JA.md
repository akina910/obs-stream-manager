# OBS Stream Manager 0.2.18 更新手順

## 更新するタイミング

配信・録画・リプレイを終了してから更新してください。OBS Stream ManagerとOBS Studioの両方を終了します。

## 更新方法

1. `OBS Stream Manager-Setup-0.2.18-x64.exe`を実行します。
2. インストール完了後にOBS Studioを起動します。
3. OBS Stream Managerが自動起動しない場合だけ、スタートメニューから一度起動します。
4. 画面上部のOBS副出力プラグイン表示が`0.2.18`になっていることを確認します。

設定、ゲームプロファイル、YouTube/Twitch接続、BGMライブラリは削除されません。Portable版ではなくSetup版を使うと、OBS副出力プラグインも同時に更新されます。

## 0.2.18で直る内容

- Twitch副出力のAAC音声をYouTube側と同じA6 `STREAM MIX`エンコーダーから共有し、映像だけ進んで公開音声が無音になる経路を修正
- 録画へA6 `STREAM MIX`を追加し、A1ゲーム、A2 Discord、A3マイク、A4 BGM、A5 AUXと一緒に実出力を検証可能に変更
- GFNのウィンドウタイトルからゲームを自動判定し、選択中プロファイルとキャプチャ対象を維持
- ARKに残っていた旧形式の二重マイクゲインを安全値へ制限
- OBS停止後はYouTubeの画面反映を待たず、すぐ「OBS送信停止済み」と表示
- 正常なBGM Stock移行をエラー風の警告として表示しない

## 更新直後の確認

ARKを選択し、GFNのARK画面がOBSへ映っていることを確認します。短い非公開テスト配信と録画で、A6 `STREAM MIX`にゲーム音とマイクが入ることを確認してから本配信を開始してください。
