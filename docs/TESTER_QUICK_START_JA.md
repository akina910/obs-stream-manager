# OBS Stream Manager 0.2.20 テスター向け使い方

## インストール

1. 配信・録画を終了し、OBSとOBS Stream Managerを閉じます。
2. `OBS Stream Manager-Setup-0.2.20-x64.exe`をダブルクリックします。既定の場所へアプリとOBSプラグインが自動で入ります。
3. 画面に案内が出た場合だけOBSを一度終了します。Stream Managerが接続、FHD 60 FPS、録画音声トラックを自動準備するので、次にOBSを起動します。

以前のバージョンを使っていた場合、ゲームプロファイルや接続情報はそのまま引き継がれます。

このテスター版はコード署名されていないため、WindowsのSmartScreen警告が表示される場合があります。受け取ったファイル名と同梱の`SHA256SUMS.txt`を確認したうえで、「詳細情報」から実行してください。想定していない相手や場所から入手したファイルは実行しないでください。

## 最初にやること

1. 使うゲームプロファイルを選びます。
2. 「音声設定」でマイク、ゲーム音、Discord、BGMを確認します。
3. マイク音量と安全フィルターは自動で適用されます。実際の声量に合わせる場合は「開始してゲームへ戻る」を押し、ゲームへ戻って普段どおり話します。ゲーム音も取れれば相対バランスまで、無音ならゲーム音量を変えずマイクだけを15秒測定します。
4. 配信先を確認して「配信開始」を押します。

ゲーム音は選択中ゲームだけ、DiscordはDiscordだけを自動で取り込みます。旧設定がスピーカー全体を複数ソースで取り込んでいた場合も、ゲーム選択時に重複を外すため、利用者がOBSの音声ソースを作り直す必要はありません。

OBS WebSocketの手入力やプラグインの手動コピーは不要です。
Focusriteなど片側入力のオーディオインターフェイスを使う場合、マイクは自動でモノラル化され、録画の左右両方から同じ声が聞こえるようになります。
マイクフェーダーが上限でも小さい場合は、専用の追加ブーストをゲームプロファイルへ自動保存します。

## 録画の音声トラック

- A1: ゲーム音
- A2: Discord
- A3: マイク
- A4: BGMとBGMストック
- A5: キャプチャ内蔵音声、OBSのグローバル音声、ブラウザ・メディアなどの追加音源
- A6: YouTube/Twitchへ送る全体ミックス

OBSが基本出力モードだった場合も、OBS停止中に詳細出力モードとこの割当へ自動変更します。切替前の古い出力機構では配信・録画を開始しません。

## 配信・録画画質

ゲーム選択時と配信開始前に、OBSを次の安定設定へ自動調整します。OBS側での手入力は不要です。

- 1920×1080、60 FPS
- OBSで選択中のH.264エンコーダー（検証環境はNVENC）、YouTube CBR 10000 kbps／Twitch CBR 6000 kbps、キーフレーム2秒、Bフレーム2、look-ahead無効
- キーフレーム間隔2秒、Bフレーム2
- AAC 160 kbps
- 録画は同じ1080p配信エンコーダーを再利用

YouTubeとTwitchの同時配信はFHD 60 FPSで行います。Source Recordは個別のフレーム落ちを監視できないため配信中は使用せず、通常録画のA1〜A5へ素材を分離します。同時配信中は縦型録画も開始せず、両配信を優先します。

## 接続できない場合

以前に接続済みのアカウントはそのまま利用できます。新しいPCや新しいGoogle/Twitchアカウントでは、配布用OAuthアプリの外部承認が完了するまで初回接続が使えない場合があります。その場合は、表示されたエラー画面をスクリーンショットして報告してください。

## 不具合報告に必要なもの

- 何を押したときに起きたか
- OBS画面のスクリーンショット
- OBSの「ヘルプ → ログファイル → 現在のログファイルを表示」で開いたログ
- 録画不具合の場合は、問題が分かる短い録画ファイル
